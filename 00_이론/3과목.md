운영체제 종류와 unix

1. 운영체제의 개념과 종류
- 운영체제(os)는 사용자와 하드웨어 사이에서 CPU, 메모리, 파일, 입출력 장치 같은 자원을 관리하고, 사용자가 컴퓨터를 편하게 쓰도록 돕는 시스템 소프트 웨어
- PC에는 Windows, 서버에는 UNIX, Linux, 스마트폰에는 Android, IOS처럼 쓰임새마다 대표 운영체제 다름

 * 운영체제 : 컴퓨터 자원을 효율적으로 관리, 사용자에게 편리한 인터페이스를 제공하는 시스템 소프트웨어 
 * 성능 평가 기준 : 처리능력(Throughput) ^, 반환시간(Turnaround Time) v , 사용가능도(Availability) ^, 신뢰도 (Reliavility) ^
 * UNIX : AT&T 벨 연구소의 켄 톰슨 , 데니스 리치가 개발 -> 커널과 쉘로 구성
   +  대부분 C언어로 작성 -> 이식성 높음, 다중 사용자, 다중 작업, 계층적 트리 파일 시스템
 * Linux : 리누스 토스발스가 UNIX를 기반으로 개발한 오픈 소스 운영체제
 * macOS / iOS : 애플이 UNIX 기반으로 갭라한 운영체제 (PC/ 모바일)
 * Android : 구글이 리눅스 커너 기반으로 개발한 개방형 모바일 운영체제 -> Java, Kotlin으로 앱 개발

> 대표 운영체제 비교
Windows | 마이크로 소프트 | GUI 중심 , 개인용 PC에서 가장 널리 사용
UNIX | AT&T 벨 연구소 | C언어, 다중 사용자, 서버용, 커널/쉘 구조
Linux | 리누스 토르발스 | Unix 호환, 오픈소스, 서버, 임베디드
macOS/ iOS | 애플 | UNIX 기반, 애플 기기 전용
Android | 구글 | 리눅스 커널 기반 개방형 모바일 OS

| 데니스 리치, 켄 톰슨, 벨 연구소, C언어 = UNIX

2. UNIX의 구조 : 커널과 쉘
- UNIX는 양파처럼 층으로 되어 있음, 가운데 하드웨어를 직접 다루는 커널이 있고, 그 바깥에 사용자의 명령을 받아 커널에 전달하는 쉘이 있음
- 사용자는 쉘에 명령을 입력할 뿐, 하드웨어를 직접 만지지x(이 구조 덕분에 하드웨어가 보로, 쉘만 바꿔 다른 환경처럼 사용)
 * 커널(Kernel) : UNIX의 핵심, 부팅 시 주기억장치에 상주 -> 하드웨어 보호, 프로그램과 하드웨어 간 인터페이스
   + 프로세스 관리, 기억장치 관리, 파일 관리, 입출력 관리, 데이터 전송 및 변환
 * 쉘(Shell) : 사용자의 명령을 인식, 해석해 커널로 전달하는 명령어 해석기
   + 시스템과 사용자 간 인터페이스 . 반복 명령을 묶는 프로그래밍(스트립트) 기능 . 초기화 파일로 사용자 환경 설정
* 유틸리티 : 편집기 . 컴파일러 . 정렬 . 디버거 등 사용자가 쓰는 부가 프로그램

3. 쉘 종류와 환경 변수
- 쉘에도 여려 종류 
- 쉘은 환경 변수에 사용자 이름, 명령어를 찾을 경로 같은 설정을 저장해 두고 명령을 실행할 때 참고
 * 쉘 종류
   + 본 쉘(sh) -> 가장 오래됨
   + 배시 쉘(bash) -> 개선해 리눅스 기본으로 사용
   + csh -> c Shell
   + ksh -> Korn Shell
 * 환경 변수 : 쉘이 실행 환경을 설정하는데 쓰는 변수 -> 사용자별 작업 환경을 결정
 * 환경 변수 출력 . 설정 명령어  
   + set : 모든 쉘 변수 출력 . 설정
   + env / printenv : 환경 변수 출력
   + setenv : C 쉘에서 환경 변수 설정
   + export : bash에서  환경 변수로 지정

> 자주 쓰는 환경 변수
PATH : 명령어를 찾을 디렉터리 목록
HOME : 사용자의 홈 디렉터리
USER : 현재 로그인한 사용자 이름
SHELL : 사용중인 쉘의 경로
PWD : 현재 작업 디렉터리

    환경 변수 명령어 사용 예 

    | 명령                 | 동작
    printenv PATH          PATH 환경 변수 값 출력
    env                    현재 설정된 환경 변수 전체 출력
    export NAME=chch       (bash) NAME을 환경 변수로 등록
    setenv NAME chch       (csh) NAME 환경 변수 설정

4. UNIX / Linux 기본 명령어
- 쉘에 직접 입령하는 명령어는 크게 파일 . 디렉터리를 다루는 명령어, 프로세스를 다루는 명령어로 나눔

> 파일 . 디렉터리 명령어
ls | 디렉터리 안의 파일 목록 확인
pwd | 현재 작업 중인 디렉터리의 절대 경로 출력
ch / chdir | 다른 디렉터리로 이동(현재 위치 변경)
cp | 파일 복사
mv | 파일 이동, 이름 변경
rm | 파일 삭제
cat | 파일 내용을 화면에 표시
chmod | 파일의 보호 모드(접근 권한) 설정
chown | 파일의 소유자 변경
fsck | 파일 시스템 검사, 보수
> 프로세스 명령어
fork | 새로운 스로세스 생성(부모 프로세스를 복제한 자식 프로세스)
exec | 새로운 프로세스(프로그램) 수행
wait | 상위 프로세스가 하위 프로세스 종료 등의 이벤트를 기다림
getpid | 자신의 프로세스 ID 호출
getppid | 부모 프로세스 ID 호출
kill . ps | 프로세스 종료 . 실행 중인 프로세스 목록 확인
